How this editor works Login with GitHub to add rides and notes

Use this page on https://thenewsoulsearchers.de/admin/ (not www). First click the gold Login with GitHub in this bar. Then use the gold Save this ride button at the bottom-right. That writes to GitHub. The top Publish menu stays open so you can pick Publish now if you want. Then open the ride page itself (not only the list) and hard-refresh (Cmd+Shift+R). GitHub already has the text and photos. The public Worker can sit on an old build, so an empty page after Publish is the site being behind, not a lost save.

Photos: JPEG from the phone. First photo sits at the top. Photos in the story sit in the text, not in a pile at the start. The picture button in Ride text puts a photo where you are typing. Then Save this ride. iPhone HEIC is a broken thumb here. Settings → Camera → Formats → Most Compatible, or export a JPEG from Photos.

Shots: one photo and a line. They show on Now, newest first.

Mail and imprint: click the gold Mail button in this bar. A form opens on top. Type your email, street, and city, then Save mail and imprint. Then open Contact and Imprint and hard-refresh.

Instagram: open Site, then Instagram. Put the username, then paste the latest photo’s Share link.

Rides: ＋ Ride asks for a name, then opens the file. First photo sits at the top. Photos in the story sit in the text. Click a ride so it turns green, then − Ride.

Looks: the gold Looks button in this bar, or the footer on the public site.
