How this editor works Login with GitHub to add rides and notes

Use this page on https://thenewsoulsearchers.de/admin/ (not www). Use the gold Save this ride button at the bottom-right. That writes to GitHub. The top Publish menu stays open so you can pick Publish now if you want. Then open the ride page itself (not only the list) and hard-refresh (Cmd+Shift+R). GitHub already has the text and photos. The public Worker can sit on an old build, so an empty page after Publish is the site being behind, not a lost save.

Photos: JPEG from the phone. Then Save this ride. iPhone HEIC is a broken thumb here. Settings → Camera → Formats → Most Compatible, or export a JPEG from Photos.

Shots: one photo and a line. They show on Now, newest first.

Instagram: open Instagram in the editor. Put the username, then paste the latest photo’s Share link.

Rides: ＋ Ride asks for a name, then opens the file so you can add photos and your text. Click a ride so it turns green, then − Ride.

Looks: anyone can open Looks in the footer.
