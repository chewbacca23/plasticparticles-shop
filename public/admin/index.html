  2. Terminal 2: npm run dev
  3. Open this page at http://localhost:4321/admin/
  4. Click Login to Local Backend — do not use GitHub login here

Login with GitHub to add rides and notes

Use this page on https://thenewsoulsearchers.de/admin/ (not www). After Publish, wait about a minute for Cloudflare to rebuild, then hard-refresh the public site.

Photos: upload straight from your phone, any size. Big ones are shrunk here in the browser before uploading, so the thumbnail is right away. GitHub refuses to serve files over 1 MB to this preview, which is why that matters.

Shots: one photo and a line. They show on Now, newest first — people stay on the site and keep looking.

Instagram: open Instagram in the editor. Put the username, then paste the latest photo’s Share link. That one photo shows on the site so people hop into the account.
