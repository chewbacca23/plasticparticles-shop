Local editing (this works)
  1. Terminal 1: npm run cms:proxy
  2. Terminal 2: npm run dev
  3. Open this page at http://localhost:4321/admin/
  4. Click Login to Local Backend. Do not use GitHub login here
After edits: npm run build. Live saving is https://thenewsoulsearchers.de/admin/ (Login with GitHub). Shots = one photo + a line. They show on /now. Instagram in the editor: username + latest photo Share link. On Rides, ＋ Ride asks for a name, then opens the file for photos and text. Click a ride so it turns green, then − Ride. The Date on a ride puts it first on the site. Newest first.
Login with GitHub to add rides and notes

Use this page on https://thenewsoulsearchers.de/admin/ (not www). After Publish, then Publish now. If the button says Published, GitHub already has this ride. Add a JPEG or type in the story first. After it saves, wait about a minute for Cloudflare to rebuild, then hard-refresh the public site.

Photos: JPEG from the phone. iPhone HEIC is a broken thumb here. Settings → Camera → Formats → Most Compatible, or export a JPEG from Photos. After Publish, wait a minute and hard-refresh the public site.

Shots: one photo and a line. They show on Now, newest first. People stay on the site and keep looking.

Instagram: open Instagram in the editor. Put the username, then paste the latest photo’s Share link. That one photo shows on the site so people hop into the account.

Rides: ＋ Ride asks for a name, then opens the file so you can add photos and your text. Click a ride so it turns green, then − Ride. The Date puts a new ride first. Wait a minute, then hard-refresh the public site.
